2. Термины

Приложение — программа для мобильных устройств You&Me, распространяемая через App Store и RuStore.

Дополнительные функции (далее также «Премиум») — возможности Приложения, доступные только при наличии оплаченного доступа. Их состав описан на странице Премиум и может расширяться.

Пространство пары — общая учётная область двух пользователей Приложения, связанных между собой в Приложении, либо одного пользователя до присоединения второго.

Код привязки — последовательность из шести символов, которую Приложение показывает пользователю и которая однозначно указывает на Пространство пары.

Заказчик — дееспособное физическое лицо, акцептовавшее настоящую оферту.
