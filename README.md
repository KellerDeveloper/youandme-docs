# youandme-docs

Public pages for the **You&Me** iOS app, served by GitHub Pages. Plain HTML, no build step —
edit a file, commit, push, it is live in a minute.

| Page | Used in App Store Connect as |
|---|---|
| `privacy.html` | Privacy Policy URL |
| `support.html` | Support URL |
| `delete-account.html` | Account deletion instructions |

Update the `Last updated` line at the top of a page whenever its content changes.
