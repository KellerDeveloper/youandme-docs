Сбор, запись, систематизация, накопление, хранение, уточнение (обновление, изменение), извлечение, использование, передача (предоставление доступа партнёру, с которым вы связали пространство, поручение обработки лицам, названным в пункте 5, и трансграничная передача в объёме, описанном в пункте 6), блокирование, удаление, уничтожение. Обработка ведётся смешанным способом — автоматизированно и без использования средств автоматизации.

5. Где хранятся данные и кому поручена обработка

Данные хранятся и обрабатываются на территории Российской Федерации — в Яндекс Облаке, зона ru-central1: база данных YDB, файлы в Object Storage, сервер на Cloud Functions и API Gateway, письма с кодом входа через Cloud Postbox. Яндекс Облако обрабатывает данные по поручению оператора и не вправе использовать их в своих целях.

До сентября 2026 года данные хранились на серверах Google (Firebase) за пределами России. Сейчас хранение перенесено в Россию, а копии в Firebase удаляются по завершении переезда.

6. Трансграничная передача

Вы соглашаетесь на трансграничную передачу своих персональных данных в ограниченном объёме и только для двух целей:

  • вход в аккаунт — обмен с Apple Inc. и Google LLC при проверке подписанного токена входа;
  • доставка уведомлений — Apple Inc. (Apple Push Notification service) получает имя партнёра, сделавшего запись, вид события и ссылку на раздел, а для общей фотографии — ссылку на неё; Google LLC (Firebase Cloud Messaging, только для Android) получает название раздела, вид события и идентификатор записи — без имени и без содержимого.

Содержимое ваших записей, файлы, документы и письма капсул за пределы Российской Федерации не передаются. Без этого согласия уведомления и вход через Apple или Google работать не могут.

7. Кому данные становятся доступны

Ваши записи доступны вам и одному партнёру, с которым вы связали общее пространство по коду приглашения. Связав пространство, вы предоставляете партнёру доступ к записям, которые в нём находятся. Другим пользователям приложения ваши данные недоступны. Оператор как владелец облачного проекта технически имеет административный доступ к базе и использует его только для устранения сбоев и исполнения требований закона.
